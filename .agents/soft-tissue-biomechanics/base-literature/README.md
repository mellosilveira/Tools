# Base Literature & Constitutive Theory (PPEMM/UFCIRJ)

Core repository for **Academic Literature, Verified Bibliographies, and Constitutive Theory Specifications** supporting the Master's thesis in Soft Tissue Biomechanics and the `MelloSilveiraTools` JOSS submission.

## Folder Contents

* **[`evidence-funnel-bibliography.md`](./evidence-funnel-bibliography.md)**: Consolidated and deduplicated bibliographic catalog of the 4-stage Evidence Funnel (**301 unique verified entries** extracted from 358 audited search records), including exact search queries per stage.
* **[`comparative-mechanics-soft-tissues-vs-polymers.md`](./comparative-mechanics-soft-tissues-vs-polymers.md)**: Comparative mechanical framework between native biological soft tissues (knee ligaments, tendons, cartilage) and synthetic polymeric biomaterials across 5 domains, backed by **60 CrossRef-verified peer-reviewed studies**.
* **[`markdown-books/fung-biomechanics-base.md`](./markdown-books/fung-biomechanics-base.md)**: Y. C. Fung's *Biomechanics* converted to plain-text Markdown for formula verification and citation.
* **`theory-cheat-sheets/`**: Rigorous constitutive and numerical theory specifications:
  * [`fung-qlv-3d.md`](./theory-cheat-sheets/fung-qlv-3d.md): 3D continuum and 1D uniaxial Fung QLV formulations, reduced relaxation function $G(t)$, and implementation mapping in `MelloSilveiraTools`.
  * [`sensitivity-analysis-and-continuation.md`](./theory-cheat-sheets/sensitivity-analysis-and-continuation.md): Analytical sensitivity gradient vectors ($\nabla_{\mathbf{p}} \sigma$), normalized elasticity indices, Euler-Newton iso-stress continuation, and 10 CrossRef/ISBN-verified references.

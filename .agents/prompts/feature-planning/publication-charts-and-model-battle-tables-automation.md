# Architectural & Implementation Plan — Module 09: Publication Charts and Model Battle Tables Automation

## 1. Overview & Objectives

Specifies the architecture and implementation phases for the **Automated Scientific Post-Processing and Publication Pipeline**, fully containerized in Docker:

1. Consume raw CSV outputs and relational metadata generated by `MelloSilveiraTools` and FEBio.
2. Programmatically generate **international journal-grade static figures** (vector PDF/SVG and raster TIFF $\ge 300\text{ DPI}$), meeting typography and column-width rules for high-impact journals (e.g., *Journal of Biomechanics*, *Acta Biomaterialia*).
3. Automatically compile **Model Battle Tables** in LaTeX (`booktabs`) and Markdown, deterministically computing consolidated statistical metrics ($RMSE$, $R^2$, asymptotic error, $p$, AIC/BIC, runtime, and iterations) without manual transcription.
4. Guarantee full mathematical traceability and reproducibility before thesis or manuscript insertion.

---

## 2. Strategic & Methodological Rationale (The "Why")

* **Static figures separated from the interactive frontend:** The frontend (Blazor/Canvas) targets real-time exploration, whereas journal publication graphics demand LaTeX-matched typography (*Computer Modern* serif fonts, TeX math `$...$`, strict 85 mm single-column or 170 mm double-column widths, and controlled stroke weights), provided by dedicated Python/Matplotlib scripts.
* **100% programmatic comparative tables:** Benchmarking multiple constitutive models (Fung QLV, Schapery, Maxwell, HGO, etc.) across dozens of specimens covering all **4 ligaments (ACL, PCL, MCL, LCL)** produces hundreds of parameters and error metrics; generating tables directly from PostgreSQL and CSVs eliminates human transcription errors.
* **Dockerized Python execution:** Complies with the workspace rule banning loose host research stacks by running Pandas, SciPy, Matplotlib, and Seaborn inside an isolated container with mapped volumes.

## 3. Architecture & File Structure

**Pipeline Flow:**
Inputs (`{Model}_{Sample}_Simulation.csv`, `{VariableName}_SensitivityAnalysis.csv`, PostgreSQL `storage_entry_metadata` and `parametric_sweeps`) → Docker Volume → `publication-pipeline` container (`python:3.12-slim`) → Final artifacts (`outputs/figures/fig_relaxation_triad.pdf`, `outputs/figures/fig_sensitivity_oat.tiff`, `outputs/tables/table_model_battle.tex` and `.md`).

```text
scripts/publication_pipeline/
├── Dockerfile
├── requirements.txt
├── docker-compose.publication.yml
├── styles/
│   └── thesis_style.mplstyle            # DPI, TeX fonts, sizes, and colorblind-friendly palette
├── generators/
│   ├── figure_relaxation_triad.py       # Triad overlay: Experimental, 1D C#, 3D FEBio
│   ├── figure_residuals.py              # Pointwise residual panel over time
│   ├── figure_sensitivity_oat.py        # 2x2 panel covering all 4 mandatory OAAT scenarios
│   └── table_model_battle.py            # LaTeX booktabs + Markdown table compiler
├── audit_outputs.py                     # Deterministic inspection of DPI, bounding boxes, and values
├── runner.py                            # Batch CLI orchestrator
└── outputs/
    ├── figures/                         # Vector PDFs and TIFFs (>= 300 DPI)
    └── tables/                          # Final .tex and .md tables
```

## 4. Implementation Phases

### Phase 1: Containerized Publication Environment & Typographic Styling
1. Create `scripts/publication_pipeline/` and a `Dockerfile` based on `python:3.12-slim`.
2. Configure `requirements.txt`: `matplotlib`, `seaborn`, `pandas`, `scipy`, `psycopg2-binary`.
3. Create `styles/thesis_style.mplstyle`:
   * TeX typography (`text.usetex: true` or standard TeX math fonts);
   * Serif font (`font.serif: Computer Modern Roman`);
   * Standardized sizes: Titles (10 pt), Axes (8 pt), Legends (7 pt);
   * Colorblind-friendly palettes (e.g., Okabe-Ito / Viridis);
   * Default raster export resolution: 300 DPI.

### Phase 2: Triad, Residual, and Sensitivity Figure Generators
1. **Triad Relaxation Curves (`figure_relaxation_triad.py`):**
   * Read raw experimental CSV, 1D C# simulation curve, and 3D FEBio curve.
   * Render real experimental spread as a **continuous shaded band** (central median $\pm$ interquartile range $Q_1\text{–}Q_3$).
   * Overlay theoretical curves with **distinct line styles and weights (solid, dashed, dash-dot)**.
   * Format for **single-column (85 mm)** and **double-column (170 mm)** layouts.
2. **Pointwise Residual Panel (`figure_residuals.py`):**
   * Compute instantaneous residual $\Delta\sigma(t) = \sigma_{\text{exp}}(t) - \sigma_{\text{sim}}(t)$.
   * Plot **zero-reference horizontal line** and **error tolerance bands**.
3. **2×2 Sensitivity Analysis Panel (`figure_sensitivity_oat.py`):**
   * Read partitioned `{VariableName}_SensitivityAnalysis.csv` files.
   * Generate an integrated 4-quadrant panel:
     * **Quadrant A:** Initial stress $\sigma(t_0)$ vs. Parameter;
     * **Quadrant B:** Final stress $\sigma(t_f)$ vs. Parameter;
     * **Quadrant C:** Asymptote time $t_{\text{asymptote}}$ vs. Parameter;
     * **Quadrant D:** Relative stress variation $\Delta\sigma$ vs. Parameter.

### Phase 3: LaTeX Model Battle Table Compiler
1. Implement `table_model_battle.py` querying PostgreSQL tables and simulation CSVs to deterministically compute:
   * Number of free parameters ($p$);
   * Global Root Mean Square Error: $RMSE = \sqrt{\frac{1}{N}\sum (\sigma_{\text{exp}} - \sigma_{\text{sim}})^2}$;
   * Ramp-phase $RMSE$ vs. Relaxation-phase $RMSE$;
   * Coefficient of determination ($R^2$) and parsimony information criteria (AIC/BIC);
   * Relative asymptotic plateau error: $\Delta\sigma_{\%} = \frac{|\sigma_{\text{exp}}(t_f) - \sigma_{\text{sim}}(t_f)|}{\sigma_{\text{exp}}(t_f)} \times 100$;
   * Mean computational runtime (ms) and iterations to convergence.
2. Export `outputs/tables/table_model_battle.tex` using `booktabs` (`\toprule`, `\midrule`, `\bottomrule`) with `siunitx` numeric column alignment.
3. Simultaneously export a corresponding Markdown version (`outputs/tables/table_model_battle.md`) for quick repository inspection.

### Phase 4: Editorial Audit & Traceability Pipeline
1. Implement `audit_outputs.py`:
   * Verify raster resolution ($\ge 300\text{ DPI}$ in TIFF/PNG outputs);
   * Check for clipped labels or axes in bounding boxes;
   * Validate exact numerical equality (zero deviation tolerance) between the LaTeX table and database source values.
2. Submit generated artifacts to `high-standard-paper-reviewer` and `documentation-and-tracking-secretary` for formal approval prior to thesis Results chapter inclusion.
